FOLD/MAP CLASSIFICATION
=======================

To enable fold/map classification, add comments to your source files:

Example in Compiler.hs:
-----------------------
```haskell
-- PASS_TYPE instCountPass: fold
-- PASS_TYPE blockCountPass: map
-- PASS_TYPE memoryOpStatsPass: fold
```

The script will automatically read these annotations and classify passes.

Format: -- PASS_TYPE <passName>: <fold|map>

SCIENTIFIC NOTATION FORMATTING
==============================

Times are now formatted intelligently:

< 0.01 ms (< 1e-5 s): Scientific notation (e.g., 3.27e-06)
0.01 - 1 ms:           3 decimal places (e.g., 0.327)
> 1 ms:                2 decimal places (e.g., 12.34)

This ensures you always see significant digits!

Example LaTeX output:
3.27e-03  (instead of 0.00 which was unreadable)

HOW TO USE
==========

1. Add fold/map annotations to your source files:
   -- PASS_TYPE instCountPass: fold
   -- PASS_TYPE blockCountPass: map

2. Run the benchmark:
   ./gibbon_benchmark.py --generate-paper

3. You get:
   - performance_table.tex with multiple tables
   - Improved figures in figures/ directory
   - Per-program heatmaps in figures/heatmaps/

4. Include in your paper:
   \input{performance_table.tex}  % All tables
   \includegraphics{figures/speedup_comparison.pdf}
   \includegraphics{figures/heatmaps/Compiler_heatmap.pdf}
   \includegraphics{figures/pass_breakdown_all.pdf}
