WHAT YOU NEED TO DO
====================

1. Annotate Your Source Files
   ---------------------------
   Add these comments to your .hs files:
   
   -- PASS_TYPE instCountPass: fold
   -- PASS_TYPE blockCountPass: map
   -- PASS_TYPE memoryOpStatsPass: fold
   
   See: FOLD_MAP_ANNOTATION_EXAMPLE.txt

2. Run The Benchmark
   ------------------
   ./gibbon_benchmark.py --generate-paper

3. You Get
   -------
   • performance_table.tex (multiple tables!)
   • figures/speedup_comparison.pdf (fold/map bars)
   • figures/heatmaps/Compiler_heatmap.pdf (per-program)
   • figures/heatmaps/List_heatmap.pdf
   • figures/pass_breakdown_all.pdf (improved)
   • ... and more

QUICK START
===========

Step 1: Annotate one program
   Edit programs/AoS/Compiler.hs:
   Add: -- PASS_TYPE instCountPass: fold

Step 2: Run benchmark
   ./gibbon_benchmark.py --programs Compiler.hs --generate-paper

Step 3: Check output
   cat performance_table.tex
   open figures/heatmaps/Compiler_heatmap.pdf

Step 4: Annotate remaining programs

Step 5: Full run
   ./gibbon_benchmark.py --clean --generate-paper --iterations 50
